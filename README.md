# Grupa-40-TPTP-2026
#  Online Shop – Prodaja namještaja

##  HomeStyle

Ovaj projekat predstavlja web stranicu za online shop prodaje namještaja, koja omogućava korisnicima pregled kataloga proizvoda i jednostavno naručivanje. U aplikaciji su prikazane različite kategorije namještaja (npr. stolovi, stolice, ormari), uz osnovne informacije kao što su cijena, opis i dostupnost proizvoda.
U izradi ovog projekta koristili smo HTML, CSS, JavaScript bez korištenja dodatnih frameworka.
